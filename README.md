# Design Automation

A UI/UX designer's workflow for creating designs and code with AI. Featuring **Vibecoding**—a methodology that uses different reference sources to guide AI-generated designs and code.

## What's Vibecoding?

Instead of writing long prompts, show AI what you want. One reference + one prompt = working output.

**4 proven flows:**

1. **Internet Reference** – Extract from design images (Dribbble, Behance, Pinterest)
2. **Design System Reference** – Use existing design systems (Apple, Airbnb, Airtable)
3. **Live Product Code** – Learn from existing codebase, create variations
4. **Figma Reference** – Connect to Figma, AI generates the code

All examples here are **single-shot results**—no fine-tuning, no iterations.

## The Idea

Good reference > Long prompt.

Show, don't tell. The quality of your output depends on how well you frame the reference, not on how well you write the prompt.
