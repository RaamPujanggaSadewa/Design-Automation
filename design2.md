# Overview

Classic Microsoft Windows 95/98 desktop interface emphasizing
functional, pixel-perfect UI with beveled controls, compact layouts, and
cascading menus.

# Colors

-   **Primary (#C0C0C0):** Window/menu background.
-   **Secondary (#808080):** Shadow edges.
-   **Tertiary (#000080):** Active selection.
-   **Accent (#008080):** Desktop background.
-   **Neutral (#FFFFFF):** Highlights.
-   **Text (#000000):** Primary text.

# Typography

-   MS Sans Serif
-   8pt bitmap rendering
-   Compact spacing
-   High readability on CRT displays

# Layout

-   Left-aligned navigation
-   Cascading menus
-   Fixed-width panels
-   Dense information hierarchy

# Components

-   Start Menu
-   Menu Items
-   Cascading Submenus
-   Pixel-art Icons
-   Beveled Borders

# Design Principles

-   Function over decoration
-   High information density
-   Consistency
-   Keyboard accessibility
-   Pixel-perfect alignment
